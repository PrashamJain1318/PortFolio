## ⚙️ Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to project:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
